The platform delivers one capability set spread across 28 modules. This page condenses the [SRS](/en/docs/srs) into a single matrix: for each module, the capabilities it delivers, the actions each capability exposes, and the user story behind it. Read it whole to see the product shape, then follow the trace into the module's requirement page.

**Reading guide**

- The **Traces** column cites FR-* and UF-* IDs as bare text; scripts link them to the [requirements](/en/docs/srs) and [user flows](/en/docs/user-flows) pages.
- The **User story** column is the product voice of the same requirements — no new behavior is introduced here.
- **Actions** are the verbs the capability exposes, not an API listing; the API surface is defined by the [requirements](/en/docs/srs/requirements/api).
