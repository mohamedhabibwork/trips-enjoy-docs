This is the complete catalog of the platform's automated processes: countdowns that expire things, retries that chase failures, and named jobs the acceptance tests call by name — the daily job, the hourly job, the archive job, the reset job, the payout run and the reconciliation. Each entry cites its rules; the linked workflow page tells the full story.
