## 4. كتالوج أنواع الجداول المرجعية

تُزرع بالقيمة `is_system = true`. يمكن لمشرف المنصة إضافة قيم إلى الأنواع المعلَّمة بـ "extensible" فقط.

يُعرَّف كل صف في الجداول المرجعية بـ `id BIGINT` (مفتاح أساسي داخلي)، ويحمل `code` ثابتًا مع تسميات JSONB قابلة للترجمة في `name` / `description`. وتشير المفاتيح الخارجية إلى `lookups.id` (باسم `*_id`، مثل `status_id`) — وليس إلى `code` أبدًا. و`code` هو الاسم العام الثابت: تخاطب واجهات API والبيانات المزروعة وشاشات الإدارة القيمة عبر `code`، وتستخدم عمليات الربط `id`، ولا يحمل أي قيمة مرجعية `uuid` (SRS [DAT-10](/ar/docs/srs/data#62-عزل-البيانات)). ويسمّي عمود "يُشار إليه بصيغة" في الكتالوج العمودَ الذي يغذيه كل نوع.

| نوع الجدول المرجعي | القيم | قابل للتوسعة | يُشار إليه بصيغة |
|---|---|---|---|
| account_status | active, suspended, deletion_requested, closed | لا | `users.status_id` |
| role | traveler, organization_owner, organization_employee, platform_driver, platform_photographer, org_driver, org_photographer, moderator, admin_super, admin_operations, admin_finance | لا | `user_roles.role_id` |
| application_type / application_status | انظر 3.3 | لا | `applications.type_id`, `applications.status_id` |
| decision_reason, suspension_reason | قائمة D-234 | نعم | `application_decisions.reason_id`, `users.suspended_reason_id` |
| trip_status, booking_status, seat_status, deal_status, subscription_status, coupon_status, lab_test_status | انظر القسم 7 من SRS | لا | أعمدة `*_status_id` في الجداول trips و bookings و trip_seats و deals و subscriptions و coupons و lab_tests |
| pricing_model | free, per_person, by_quantity, per_group, tiered | لا | `programs.pricing_model_id` |
| payment_method, gateway | انظر 3.1 | نعم | `market_payment_methods.method_id` / `gateway_id`, `payments.method_id` / `gateway_id` |
| incident_category | safety, medical, vehicle_fault, lost_traveler, conduct, other (D-331) | لا | `incidents.category_id` |
| dispute_type | booking, payment, refund, supplier_conduct, organization_conduct, other (D-254) | لا | `disputes.type_id` |
| notification_category | account, booking, payment, trip_reminder, trip_day, deal, application, lab_test, plan, promotion, safety | نعم | `notification_preferences.category_id` |
| trip_category | school, corporate, religious, tourism, event, other | نعم | `trips.category_id` |
| permission_area | trips, bookings, operations, accounting, coupons, employees, fleet, subscription, integrations, analytics | لا | `permissions.area_id` |

## 5. قابلية التتبع

انتقلت سياسات الأمان على مستوى الصفوف وكتالوج الصلاحيات ونطاقات مفاتيح API إلى [التحكم في الوصول (ACL)](/ar/docs/erd/acl).
