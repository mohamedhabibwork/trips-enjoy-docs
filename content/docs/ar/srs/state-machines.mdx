### 7.1 دورة حياة الرحلة

الحالات: مسودة، منشورة، قيد التفاوض، جاهزة، قيد الامتلاء، مكتملة العدد، قيد التنفيذ، مكتملة جزئيًا، مكتملة، قيد المعالجة اللاحقة، مؤرشفة، ملغاة، تم صرف الاستردادات.

| من | الحدث | الحارس | إلى |
|---|---|---|---|
| (لا شيء) | تنشئ الجهة المنظِّمة رحلة | خطة نشطة؛ السوق يعمل | مسودة |
| مسودة | النشر علنًا أو لجهات مستهدفة | اكتمل المعالج؛ لم يُبلغ حد الرحلات النشطة | منشورة |
| منشورة | بدء صفقة عبر المنصة | تشغيل خانة واحدة على الأقل عبر مورّد من المنصة | قيد التفاوض |
| قيد التفاوض | إنهاء صفقة المنصة الأخيرة | لكل مركبة سائق ومشرف ([BRL-07](/ar/docs/brd/requirements#7-قواعد-العمل)) | جاهزة |
| منشورة | تشغيل المركبة الأخيرة بموظفين تابعين للجهة | [BRL-07](/ar/docs/brd/requirements#7-قواعد-العمل) | جاهزة |
| منشورة أو قيد التفاوض أو جاهزة | تبلغ المقاعد المحجوزة 80% من السعة | D-189 | قيد الامتلاء |
| قيد الامتلاء | امتلأت كل مركبة | | مكتملة العدد |
| مكتملة العدد | التفريج عن مقعد | | قيد الامتلاء |
| قيد الامتلاء | هبوط المقاعد المحجوزة دون 80% | (مقترح) | جاهزة، أو منشورة إن لم تكن جاهزة بعد |
| جاهزة أو قيد الامتلاء أو مكتملة العدد | انطلاق المركبة الأولى | بلوغ وقت بدء الرحلة؛ الرحلة جاهزة ([BRL-07](/ar/docs/brd/requirements#7-قواعد-العمل)) | قيد التنفيذ |
| قيد التنفيذ | طلب الإلغاء | غير مسموح (D-25)؛ تدفق الحوادث فقط | قيد التنفيذ |
| قيد التنفيذ | انتهت بعض المركبات | انتهت واحدة على الأقل والبقية تعمل | مكتملة جزئيًا |
| قيد التنفيذ أو مكتملة جزئيًا | انتهت المركبة الأخيرة | قُدِّمت جميع تقارير الرحلة | مكتملة |
| مكتملة | بدء التسوية | تلقائي | قيد المعالجة اللاحقة |
| قيد المعالجة اللاحقة | مهمة الأرشفة | بعد 30 يومًا من الاكتمال وإغلاق التسوية ([BRL-25](/ar/docs/brd/requirements#7-قواعد-العمل)) | مؤرشفة |
| من المسودة حتى مكتملة العدد | إلغاء من الجهة المنظِّمة أو مشرف المنصة | سُجِّل السبب؛ وضُعت استردادات كاملة في قائمة الانتظار ([BRL-30](/ar/docs/brd/requirements#7-قواعد-العمل)) | ملغاة |
| ملغاة | تأكيد جميع الاستردادات | كل حجز مؤكد حالته تم الاسترداد | تم صرف الاستردادات |
| تم صرف الاستردادات | مهمة الأرشفة | بعد 30 يومًا | مؤرشفة |

### 7.2 الحجز

الحالات: السلة، مقاعد محجوزة مؤقتًا، بانتظار الدفع، مؤكد، فشل الدفع، تم تسجيل الحضور، تم تسجيل المغادرة، ملغى، بانتظار الاسترداد، تم الاسترداد.

| من | الحدث | الحارس | إلى |
|---|---|---|---|
| (لا شيء) | يبدأ المسافر حجزًا | الرحلة قابلة للحجز؛ المسافر ليس في فترة سماح الحذف | السلة |
| السلة | اختيار مقاعد أو حجز سعة (تعيّنها الجهة) | مقاعد شاغرة؛ يبدأ الحجز المؤقت؛ يُثبَّت السعر | مقاعد محجوزة مؤقتًا |
| مقاعد محجوزة مؤقتًا | المتابعة إلى الدفع | الحجز المؤقت نشط؛ المحاولات أقل من 3 | بانتظار الدفع |
| مقاعد محجوزة مؤقتًا | انتهاء الحجز المؤقت | 15 دقيقة | السلة (تُحفظ السلة، D-191) |
| بانتظار الدفع | نجاح بوابة الدفع | تم التحقق من رد الاتصال | مؤكد |
| بانتظار الدفع | فشل بوابة الدفع | | فشل الدفع |
| بانتظار الدفع | لا استجابة خلال 30 ثانية | | بانتظار الدفع (فحوص عند 1 و5 و10 دقائق؛ مشرف المنصة عند 15، D-30) |
| فشل الدفع | إعادة المحاولة | الحجز المؤقت نشط؛ المحاولات أقل من 3 (D-197) | بانتظار الدفع |
| فشل الدفع | انتهاء الحجز المؤقت | | السلة |
| مؤكد | يسجِّل المشرف حضور الراكب | مطابقة المركبة | تم تسجيل الحضور |
| تم تسجيل الحضور | تسجيل المغادرة عند محطة أو وجهة | | تم تسجيل المغادرة |
| تم تسجيل المغادرة | يعود الراكب للصعود عند محطة | المركبة نفسها (مقترح) | تم تسجيل الحضور |
| مؤكد | يلغي المسافر الحجز | قبل الانطلاق؛ [BRL-12](/ar/docs/brd/requirements#7-قواعد-العمل) | ملغى |
| مؤكد | تلغي الجهة المنظِّمة الرحلة | [BRL-30](/ar/docs/brd/requirements#7-قواعد-العمل) | ملغى |
| ملغى | إرسال الاسترداد | المبلغ أكبر من صفر | بانتظار الاسترداد |
| ملغى | لا استرداد مستحق | خلال أقل من 24 ساعة | ملغى (نهائي) |
| بانتظار الاسترداد | تأكيد بوابة الدفع | | تم الاسترداد |

### 7.3 المقعد

الحالات: متاح، محجوز مؤقتًا، محجوز، تم تسجيل الحضور، تم تسجيل المغادرة، مُفرَج عنه.

| من | الحدث | الحارس | إلى |
|---|---|---|---|
| متاح | اختياره عند إتمام الحجز | الاختيار الذاتي مُفعَّل، أو تعيين من الموظفين | محجوز مؤقتًا |
| محجوز مؤقتًا | نجاح الدفع | الحجز مؤكد | محجوز |
| محجوز مؤقتًا | انتهاء الحجز المؤقت | [BRL-08](/ar/docs/brd/requirements#7-قواعد-العمل) | متاح |
| محجوز | يسجِّل الراكب حضوره | مطابقة المركبة | تم تسجيل الحضور |
| تم تسجيل الحضور | يسجِّل الراكب مغادرته | | تم تسجيل المغادرة |
| تم تسجيل المغادرة | يعود الراكب للصعود | (مقترح) | تم تسجيل الحضور |
| محجوز | إلغاء الحجز قبل الانطلاق | | مُفرَج عنه |
| مُفرَج عنه | إعادة عرض المقعد | الرحلة لا تزال قابلة للحجز | متاح |

### 7.4 الصفقة

الحالات: مقترح، عرض مضاد من المورّد، عرض مضاد من الجهة المنظِّمة، قبِله أحد الطرفين، تم التعاقد، مرفوض.

| من | الحدث | الحارس | إلى |
|---|---|---|---|
| (لا شيء) | تقديم عرض من الجهة المنظِّمة أو المورّد | الخانة متاحة؛ المورّد متاح؛ الخطة تسمح | مقترح |
| مقترح أو عرض مضاد من الجهة المنظِّمة | يقدِّم المورّد عرضًا مضادًا | | عرض مضاد من المورّد |
| مقترح أو عرض مضاد من المورّد | تقدِّم الجهة المنظِّمة عرضًا مضادًا | | عرض مضاد من الجهة المنظِّمة |
| أي حالة مفتوحة | يقبل أحد الطرفين الشروط الحالية | | قبِله أحد الطرفين |
| قبِله أحد الطرفين | يقبل الطرف الآخر | الشروط دون تغيير | تم التعاقد |
| قبِله أحد الطرفين | يقدِّم الطرف الآخر عرضًا مضادًا | يُلغى القبول الأول | عرض مضاد من ذلك الطرف |
| أي حالة مفتوحة | يرفض أي من الطرفين | | مرفوض (السبب: رفض) |
| أي حالة مفتوحة | مرّت 72 ساعة على آخر عرض مضاد | [BRL-26](/ar/docs/brd/requirements#7-قواعد-العمل) | مرفوض (السبب: انتهاء المهلة) |
| أي حالة مفتوحة | المورّد موقوف لإجراء فحص المختبر | [BRL-17](/ar/docs/brd/requirements#7-قواعد-العمل) | مرفوض (السبب: إيقاف المورّد) |
| أي حالة مفتوحة | إلغاء الرحلة | | مرفوض (السبب: إلغاء الرحلة) |

### 7.5 طلب الانضمام

الحالات: مسودة، مقدَّم، بانتظار المراجعة، طُلبت تعديلات، معتمد، مرفوض، مستأنَف، مغلق.

| من | الحدث | الحارس | إلى |
|---|---|---|---|
| مسودة | يقدِّم مقدِّم الطلب | تم التحقق من جهات الاتصال حسب الدور؛ المستندات المطلوبة موجودة | مقدَّم |
| مقدَّم | يدخل قائمة الانتظار | تلقائي | بانتظار المراجعة |
| بانتظار المراجعة | الاعتماد | | معتمد (تُعيَّن الخطة، ويُنشأ المستأجر أو الملف الشخصي) |
| بانتظار المراجعة | طلب تعديلات | تُسجَّل البنود والرسالة | طُلبت تعديلات |
| بانتظار المراجعة | الرفض | يُسجَّل رمز السبب | مرفوض |
| طُلبت تعديلات | إعادة التقديم | خلال 14 يومًا، أو 21 مع تمديد | بانتظار المراجعة |
| طُلبت تعديلات | لا استجابة بحلول تاريخ الاستحقاق | [OD-32](/ar/docs/brd/compliance#11-القرارات-المفتوحة) | مغلق |
| مرفوض أو مغلق | الاستئناف | خلال 14 يومًا؛ استئناف واحد لكل رفض | مستأنَف |
| مستأنَف | قبول الاستئناف | خلال 5 أيام عمل | معتمد |
| مستأنَف | رفض الاستئناف | | مرفوض (نهائي) |
| مرفوض أو مغلق | إعادة التقديم | بعد 30 يومًا من القرار | مقدَّم (طلب جديد) |

### 7.7 الكوبون

|---|---|---|---|
