### 6.1 الكيانات الأساسية

يحتوي [ERD](/ar/docs/erd) على الجداول والأعمدة والمفاتيح والأنواع المرجعية ومسارات RLS. ويبيّن هذا الجدول غرض كل كيان ونطاق مالكه ومدة الاحتفاظ به. ويعني النطاق من يملك الصفوف: المستأجر (جهة منظِّمة واحدة)، أو المنصة، أو الحساب (شخص واحد)، أو المورّد.

| الكيان | الغرض | النطاق | جداول ERD | مدة الاحتفاظ |
|---|---|---|---|---|
| الحساب والأدوار | هوية تسجيل الدخول والأدوار الممنوحة | الحساب | users, user_roles, auth_factors, sessions, devices | حتى الحذف، ثم القسم 6.4 |
| السوق | إعدادات الدولة | المنصة | markets, market_payment_methods, tax_rates | مدى حياة المنصة |
| الجهة المنظِّمة | جذر المستأجر وإعداداته | المستأجر | organizations | مدى حياة المستأجر، ثم مدة الاحتفاظ المالي |
| العضو والأذونات | وصول الموظفين لكل جهة منظِّمة | المستأجر | organization_members, member_permissions, invitations | تُحفظ مع سجل التدقيق |
| طلب الانضمام | طلبات انضمام الجهات المنظِّمة والمورّدين | المنصة | applications, application_documents, application_decisions, appeals | [OPEN: طلبات الانضمام المرفوضة والمستندات](/ar/docs/recommendations/open-decisions#open-12) |
| ملفات المورّدين | بيانات السائقين والمصوّرين | المنصة، أو المستأجر لما تملكه الجهة المنظِّمة | driver_profiles, photographer_profiles, provider_vehicles, portfolio_items, availability_slots | مدى حياة الحساب |
| فحص المختبر | سجل فحوصات المختبر للسائق | المنصة | lab_tests, lab_partners | حسب المراجعة القانونية لكل سوق |
| نوع المركبة والمركبة | تخطيطات المقاعد والأسطول | المستأجر | vehicle_types, vehicle_type_seats, vehicles | مدى حياة المستأجر |
| الرحلة | رحلة منظَّمة واحدة بمحطاتها وجمهورها ومركباتها وموظفيها | المستأجر | trips, trip_stops, trip_audiences, trip_vehicles, trip_staff_assignments | 5 سنوات بعد حذف الحساب |
| البرنامج | الأنشطة والفئات | المستأجر | programs, program_tiers | مثل الرحلة |
| الحجز | الحجز والركاب والبرامج والمقاعد والإجراءات التصحيحية | المستأجر والمسافر | bookings, booking_passengers, booking_programs, trip_seats, booking_remedies | 7 سنوات (مالي) |
| الصفقة | التفاوض والعروض | المستأجر والمورّد | deals, deal_offers | 7 سنوات (مالي) |
| الدفع والاسترداد | مدفوعات بوابة الدفع والمحاولات والاستردادات | المستأجر أو الحساب | payments, payment_attempts, refunds | 7 سنوات |
| الكوبون | الرموز والنطاق وعمليات الاستبدال والإشارات | نطاق المنشئ | coupons, coupon_programs, coupon_audiences, coupon_redemptions, abuse_flags | عمليات الاستبدال 7 سنوات |
| الخطة والاشتراك | الكتالوج والأسعار والاشتراكات والتحصيلات والتجاوزات والعدادات | المنصة والمالك | plans, plan_limits, plan_prices, subscriptions, subscription_charges, plan_overrides, usage_counters | التحصيلات 7 سنوات |
| تسجيل الحضور والتتبع | أحداث الصعود والمواقع والحوادث والتقارير | المستأجر | checkin_events, tracking_points, incidents, trip_reports | تسجيل الحضور سنة واحدة؛ GPS 90 يومًا |
| ربط الطفل وحالة السلامة | روابط الوالدين وحالات السلامة | الوالد والمستأجر | child_links, safety_cases | سجل رحلات الطفل سنة واحدة |
| الألبوم والصورة | وسائط الرحلة والوصول إليها | المصوّر والرحلة | albums, photos, album_shared_links, album_members, download_logs | الألبومات حتى الحذف؛ سجلات التنزيل سنة واحدة |
| السجل | سجل القيد المزدوج | المنصة والمستأجر | ledger_accounts, ledger_transactions, ledger_entries | 7 سنوات |
| الفاتورة | فواتير B2C وB2B وإشعارات دائنة لجميع الأطراف | المُصدِر | invoices, invoice_lines | 7 سنوات |
| صرف المستحقات والتسوية | عمليات الصرف الأسبوعية وتسويات كل رحلة | المورّد، المستأجر | payout_runs, payouts, payout_methods, settlements, settlement_lines | 7 سنوات |
| المطابقة | فروقات بوابة الدفع | المنصة | reconciliation_exceptions | 7 سنوات |
| النزاع | النزاعات والملفات | المنصة | disputes, dispute_files | 7 سنوات |
| الإشعار | التفضيلات والرسائل وعمليات التسليم والقوالب | الحساب والمنصة | notification_preferences, notifications, notification_deliveries, notification_templates | سجلات التسليم [OPEN](/ar/docs/recommendations/open-decisions#open-13) |
| التحليلات | الأحداث والتجميعات اليومية | المستأجر والمنصة | analytics_events, analytics_daily | الأحداث 13 شهرًا (مقترح)؛ التجميعات مدى حياة المستأجر |
| الموافقة والخصوصية | الموافقات وطلبات البيانات | الحساب | consents, privacy_requests | مدى حياة الحساب زائد 7 سنوات (مقترح) |
| التدقيق | إجراءات مشرفي المنصة وتغييرات الأذونات | المنصة | audit_logs | 7 سنوات |

### 6.2 عزل البيانات

| المعرف | المتطلب | الأولوية |
|---|---|---|
| [DAT-01](/ar/docs/srs/data#62-عزل-البيانات) | كل صف تابع لمستأجر يحمل `organization_id`. وتُقيد عمليات القراءة والكتابة على المستأجر في طبقات قاعدة البيانات (RLS) والمستودع وواجهة API. | Must |
| [DAT-02](/ar/docs/srs/data#62-عزل-البيانات) | لا تجمع أي استعلام ظاهر للمستخدم بين بيانات مستأجرين مختلفين. وتُنفَّذ عمليات القراءة على مستوى المنصة كلها عبر مستودع مشرف المنصة أو المنصة وتُسجَّل. | Must |
| [DAT-03](/ar/docs/srs/data#62-عزل-البيانات) | عندما يصبح الحذف نهائيًا، تُزال الحقول الشخصية أو تُستبدل بـ«مستخدم محذوف»، باستثناء السجلات المحفوظة بموجب القسم 6.4. وتبقى سجلات الرحلة 5 سنوات. وتُلغى الحجوزات المستقبلية ويُسترد ثمنها؛ وتُدفع الأرباح المتبقية في تاريخ صرف المستحقات التالي. | Must |
| [DAT-04](/ar/docs/srs/data#62-عزل-البيانات) | تُحفظ وثائق الهوية ونتائج المختبر في حاوية مقيدة لا يراها إلا مشرفو المنصة؛ وتُدقَّق كل عملية فتح. | Must |
| [DAT-05](/ar/docs/srs/data#62-عزل-البيانات) | تُشفَّر أرقام الهواتف وأرقام الهوية والرخص وتفاصيل صرف المستحقات على مستوى العمود. | Must |
| [DAT-06](/ar/docs/srs/data#62-عزل-البيانات) | يُخزَّن المال بوحدات صغيرة مع رمز العملة؛ ويتبع التقريب [FR-MKT-05](/ar/docs/srs/requirements/mkt#fr-mkt-05--التقريب-والعرض). | Must |
| [DAT-10](/ar/docs/srs/data#62-عزل-البيانات) | تستخدم كل مسارات API والملفات معرّف UUID العام؛ ولا تترك المعرّفات الرقمية الداخلية الواجهة الخلفية أبدًا. | Must |

### 6.3 الحذف الناعم وعدم القابلية للتغيير والحذف

| المعرف | المتطلب | الأولوية |
|---|---|---|
| [DAT-07](/ar/docs/srs/data#63-الحذف-الناعم-وعدم-القابلية-للتغيير-والحذف) | تُحذف الحسابات الموقوفة والحجوزات الملغاة وطلبات الانضمام المسحوبة حذفًا ناعمًا أو تُحفظ مخفيةً عن واجهات المستخدمين ومرئيةً لمشرفي المنصة. | Must |
| [DAT-08](/ar/docs/srs/data#63-الحذف-الناعم-وعدم-القابلية-للتغيير-والحذف) | صفوف السجل والتدقيق وعروض الصفقات وتسجيل الحضور والتتبع والموافقة وقائمة الإرسال الخارجي (outbox) هي للإدراج فقط. وتكون التصحيحات صفوفًا عكسية. | Must |
| [DAT-09](/ar/docs/srs/data#63-الحذف-الناعم-وعدم-القابلية-للتغيير-والحذف) | يحتفظ الحساب المحذوف بسجلات رحلاته وماليته للمدد المذكورة في 6.4، مع إزالة الحقول الشخصية حيثما يسمح القانون. | Must |
| [DAT-11](/ar/docs/srs/data#63-الحذف-الناعم-وعدم-القابلية-للتغيير-والحذف) | الحذف الناعم موحّد: يحمل كل صف قابل للحذف الناعم `deleted_at TIMESTAMPTZ NULL` مع `deleted_by BIGINT NULL` كمفتاح أجنبي FK إلى `users.id`؛ ولا يوجد علم منطقي (boolean flag). يُعدّ الصف محذوفًا عندما تكون قيمة `deleted_at` غير فارغة، وتُصفّر عملية الاستعادة العمودَين معًا. | Must |
| [DAT-12](/ar/docs/srs/data#63-الحذف-الناعم-وعدم-القابلية-للتغيير-والحذف) | الصفوف المحذوفة حذفًا ناعمًا قابلة للاستعادة لمدة 30 يومًا، بما يتوافق مع فترة السماح لحذف الحساب ([BRL-15](/ar/docs/brd/requirements#7-قواعد-العمل)). وبعد انقضاء النافذة يبقى الصف مخفيًا ويُزال في التطهير بموجب سياسة الاحتفاظ في القسم 6.4. | Must |
| [DAT-13](/ar/docs/srs/data#63-الحذف-الناعم-وعدم-القابلية-للتغيير-والحذف) | لا يُحذف السجل ولا التدقيق ولا أي جدول غير قابل للتغيير آخر من ذكر [DAT-08](/ar/docs/srs/data#63-الحذف-الناعم-وعدم-القابلية-للتغيير-والحذف) حذفًا ناعمًا أبدًا (فلا يوجد فيه عمود `deleted_at`)، ولا يُحذف نهائيًا ضمن مدد الاحتفاظ الخاصة به. | Must |
| [DAT-14](/ar/docs/srs/data#63-الحذف-الناعم-وعدم-القابلية-للتغيير-والحذف) | يحتفظ كل جدول قابل للحذف الناعم بفهرس جزئي `where deleted_at is null` لكل استعلام ساخن (عروض القوائم، وعمليات البحث عن الصفوف النشطة، وقيود التفرّد) حتى لا تُفحص الصفوف المحذوفة أبدًا. | Must |
| [DAT-15](/ar/docs/srs/data#63-الحذف-الناعم-وعدم-القابلية-للتغيير-والحذف) | تتخذ قيود التفرّد على الجداول القابلة للحذف الناعم صورة فهارس فريدة جزئية على الصفوف الحيّة فقط: `unique (cols) where deleted_at is null`. وحيثما وجب أن تبقى قيمة صف محذوف مميِّزة لأغراض السجل، يُستخدم فهرس رفيق `unique (cols, deleted_at) where deleted_at is not null` يعتمد عمود `deleted_at` حسمًا للتساوي. | Must |

### 6.4 مدة الاحتفاظ

| البيانات | مدة الاحتفاظ | الأساس |
|---|---|---|
| الحساب خلال فترة سماح الحذف | 30 يومًا؛ تسجيل الدخول يستعيد الحساب | [BRL-15](/ar/docs/brd/requirements#7-قواعد-العمل) |
| البيانات الشخصية للحساب بعد الحذف | تُزال، باستثناء السجلات أدناه | [BRL-15](/ar/docs/brd/requirements#7-قواعد-العمل) |
| سجلات الرحلة | 5 سنوات بعد حذف الحساب | [BRL-15](/ar/docs/brd/requirements#7-قواعد-العمل) |
| الحجوزات والمدفوعات والفواتير والسجل وصرف المستحقات والصفقات | 7 سنوات | [OD-04](/ar/docs/brd/compliance#11-القرارات-المفتوحة) (بانتظار المراجعة القانونية) |
| سجل التدقيق | 7 سنوات، مع قفل الكائنات | D-04, BRD 8.5 |
| أحداث تسجيل الحضور والمغادرة | سنة واحدة | D-45 |
| نقاط GPS الخام | 90 يومًا، ثم تُحفظ ملخصة ساعية | المعمارية 18.4 |
| سجل رحلات الطفل | سنة واحدة | D-135 |
| سجلات تنزيل الألبومات | سنة واحدة | D-271 |
| رموز التحقق | 5 دقائق | [BRL-20](/ar/docs/brd/requirements#7-قواعد-العمل) |
| مفاتيح منع التكرار (idempotency) | 24 ساعة | [NFR-SEC-06](/ar/docs/srs/quality#82-الأمان-nfr-sec) |
| وثائق الهوية ونتائج المختبر | [OPEN: حسب المراجعة القانونية لكل سوق](/ar/docs/recommendations/open-decisions#open-13) | BRD 8.2 |
| سجلات تسليم الإشعارات | [OPEN](/ar/docs/recommendations/open-decisions#open-13) | غير محدد |
| سجلات التطبيق | 7 سنوات في تخزين الأرشيف | المعمارية 22.1 |
| النسخ الاحتياطية لقاعدة البيانات | لقطات يومية 35 يومًا؛ استعادة لنقطة زمنية 7 أيام؛ نسخ عبر المناطق 30 يومًا | المعمارية 22.1 |
