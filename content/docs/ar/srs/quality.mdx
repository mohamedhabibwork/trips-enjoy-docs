### 8.2 الأمان (NFR-SEC)

| المعرف | المتطلب |
|---|---|
| [NFR-SEC-01](/ar/docs/srs/quality#82-الأمان-nfr-sec) | TLS 1.3 و HSTS على كل حركة المرور؛ تثبيت الشهادة (certificate pinning) على الجوال. |
| [NFR-SEC-02](/ar/docs/srs/quality#82-الأمان-nfr-sec) | تُجزَّأ كلمات المرور باستخدام Argon2id؛ بحد أدنى 12 حرفًا؛ ويجري فحصها مقابل قوائم كلمات المرور المسربة (D-51). |
| [NFR-SEC-03](/ar/docs/srs/quality#82-الأمان-nfr-sec) | قفل الحساب بعد 5 محاولات تسجيل دخول فاشلة لمدة 15 دقيقة، لجميع الأدوار. |
| [NFR-SEC-04](/ar/docs/srs/quality#82-الأمان-nfr-sec) | العوامل الثانية لكل دور ([FR-AUTH-04](/ar/docs/srs/requirements/auth#fr-auth-04--طرق-تسجيل-دخول-خاصة-بكل-دور))؛ وقواعد OTP وفق [BRL-20](/ar/docs/brd/requirements#7-قواعد-العمل). |
| [NFR-SEC-05](/ar/docs/srs/quality#82-الأمان-nfr-sec) | رموز الوصول هي JWT موقعة بـ RS256 تحمل المستخدم والدور النشط والجهة المنظِّمة وإصدار الرمز، ويجري التحقق منها عند كل طلب؛ مدة صلاحيتها 15 دقيقة؛ وتتناوب رموز التحديث. |
| [NFR-SEC-06](/ar/docs/srs/quality#82-الأمان-nfr-sec) | تقبل نقاط النهاية المغيِّرة مفتاح idempotency يُحتفظ به 24 ساعة. |
| [NFR-SEC-07](/ar/docs/srs/quality#82-الأمان-nfr-sec) | عزل المستأجرين على مستوى قاعدة البيانات (RLS) وطبقة المستودعات وطبقة API؛ واجتياز حزمة اختبارات العزل بين المستأجرين قبل كل مرحلة. |
| [NFR-SEC-08](/ar/docs/srs/quality#82-الأمان-nfr-sec) | التشفير أثناء السكون في كل مكان؛ وتشفير على مستوى العمود للمعرِّفات المدرجة. |
| [NFR-SEC-09](/ar/docs/srs/quality#82-الأمان-nfr-sec) | الأسرار في مخزن مُدار، تُبدَّل كل 90 يومًا، ولا تظهر أبدًا في الشيفرة أو السجلات. |
| [NFR-SEC-10](/ar/docs/srs/quality#82-الأمان-nfr-sec) | أقل امتياز ممكن للخدمات والمهام وأدوار العاملين. |
| [NFR-SEC-11](/ar/docs/srs/quality#82-الأمان-nfr-sec) | تخزين مقيَّد لمستندات الهوية ونتائج المختبرات. |
| [NFR-SEC-12](/ar/docs/srs/quality#82-الأمان-nfr-sec) | لا تُستقبل بيانات البطاقات ولا تُسجَّل ولا تُخزَّن. |
| [NFR-SEC-13](/ar/docs/srs/quality#82-الأمان-nfr-sec) | حدود المعدل: غير المصادق عليهم 60 طلبًا في الدقيقة؛ المسافر 600؛ موظفو الجهة المنظِّمة 1,200؛ مشرف المنصة 3,000؛ تسجيل حضور المشرف 120 لكل مركبة في الدقيقة. السائقون والمصوّرون والوالدان [OPEN](/ar/docs/recommendations/open-decisions#open-07). |
| [NFR-SEC-14](/ar/docs/srs/quality#82-الأمان-nfr-sec) | مراجعة أمنية و SAST، وفحص التبعيات و DAST شهريًا قبل كل مرحلة؛ واختبار اختراق خارجي سنوي. |
| [NFR-SEC-15](/ar/docs/srs/quality#82-الأمان-nfr-sec) | CAPTCHA على نماذج التسجيل؛ وتقييد الحجز بـ 5 حجوزات للمسافر في الساعة ما لم يوثَّق الحساب (الهندسة المعمارية 17.4). |
| [NFR-SEC-16](/ar/docs/srs/quality#82-الأمان-nfr-sec) | تتحقق طقوس مفاتيح المرور من صحة التحدي والأصل مقابل القيم المتوقعة وفق [FR-AUTH-11](/ar/docs/srs/requirements/auth#fr-auth-11--تسجيل-مفاتيح-المرور) و [FR-AUTH-12](/ar/docs/srs/requirements/auth#fr-auth-12--تسجيل-الدخول-بمفتاح-المرور)؛ وتضمن سجلات التدقيق قابلية كشف التلاعب [OPEN: سلسلة تجزئة مقابل مخزن إضافة فقط](/ar/docs/recommendations/open-decisions#open-08) وفق [FR-ADM-10](/ar/docs/srs/requirements/adm#fr-adm-10--سجل-حدث-التدقيق). |

## 9. متطلبات الواجهات و API

### 9.1 مجموعات الموارد

| مجموعة الموارد | يغطي | الفاعلون الرئيسيون | الوحدات |
|---|---|---|---|
| المصادقة والحسابات | التسجيل، والتحقق، والجلسات، والأدوار، والخصوصية | الجميع | AUTH, TRV |
| طلبات الانضمام | التقديمات، والقرارات، والتظلومات | المتقدمون، ومشرفو المنصة | ONB |
| الجهات المنظِّمة | الإعدادات، والأعضاء، والصلاحيات، والتكاملات، والهوية البصرية | الموظفون، ومشرفو المنصة | ORG, EMP |
| الأسطول | أنواع المركبات، والمركبات | الموظفون | FLT |
| الرحلات | الرحلات، والمحطات، والمركبات، وإسناد العاملين، والبرامج، والنشر | الموظفون؛ والمسافرون للقراءة | TRIP, PRG, STF |
| الصفقات | التفاوض والعروض | الموظفون، والموردون، ومشرفو المنصة | NEG |
| الحجوزات | السلة، والحجز المؤقت، وإتمام الحجز، والإلغاء، والتعويضات، والإيصالات | المسافرون؛ والموظفون ومشرفو المنصة للقراءة | BKG, SEAT |
| المدفوعات | حالة الدفع، والاستردادات، وعمليات الاستدعاء الراجع من البوابة | المسافرون، ومشرفو المنصة | PAY |
| الكوبونات | الكوبونات، والتحقق من الصلاحية، وعمليات الاستبدال | المنشئون، والمسافرون، ومشرفو المنصة | CPN |

### 9.2 الاصطلاحات

| المعرف | الاصطلاح | الأولوية |
|---|---|---|
| IF-01 | REST بإصدار في عنوان URL (/api/v1). التغييرات الكاسرة في إصدار رئيسي جديد فقط. و OpenAPI 3.1 مولَّد من الشيفرة. | Must |
| IF-02 | JSON بترميز UTF-8؛ والأوقات بصيغة ISO 8601 مع الإزاحة؛ والأموال بصيغة `{amount_minor, currency}`؛ والموارد معرَّفة بـ UUID. | Must |
| IF-03 | مغلف واحد: `data` و `meta` عند النجاح؛ و `error` (الرمز، والرسالة بلغة الطالب، والتفاصيل) و `meta` عند الفشل؛ و `meta.request_id` دائمًا. | Must |
| IF-04 | فئات الأخطاء: VALIDATION_FAILED 400، و UNAUTHENTICATED 401، و PLAN_REQUIRED 402، و FORBIDDEN 403، و NOT_FOUND 404 (كذلك لبيانات المستأجرين الآخرين)، و CONFLICT 409، و BUSINESS_RULE_VIOLATED 422، و RATE_LIMITED 429، و INTERNAL_ERROR 500، و SERVICE_UNAVAILABLE 503. | Must |
| IF-05 | ترقيم صفحات بالمؤشر؛ الافتراضي 20، والأقصى 100 لكل صفحة (D-308). | Must |
| IF-06 | Idempotency-Key على كل طلب مغيِّر؛ المفتاح نفسه مع المتن نفسه يعيد النتيجة الأصلية؛ والمفتاح نفسه مع متن مختلف يعيد CONFLICT. | Must |
| IF-07 | الإصدارات والحقول المهجورة تعيد ترويستي Deprecation و Sunset لمدة 90 يومًا قبل الإزالة. | Must |
| IF-08 | رموز الأخطاء ثابتة؛ والرسائل مترجمة. | Must |
| IF-09 | الاستجابات المحدودة المعدل تتضمن Retry-After. | Should |
| IF-10 | تحمل أحداث webhook معرف الحدث ونوعه ووقت الحدوث وتكون موقعة (COM-04). | Must |
| IF-11 | تُمنح صلاحية الاشتراكات الفورية لكل قناة عند وقت الاشتراك: مقاعد الرحلة، ومركبة الرحلة، وطفل العائلة، والصفقة، وعمليات الجهة المنظِّمة. | Must |
| IF-12 | سجل يخص مستأجرًا آخر يعيد NOT_FOUND. | Must |

### 9.3 مصادقة API

يستخدم عملاء الطرف الأول رمز الوصول الصادر عن تسجيل الدخول. أما عملاء API العامة ([FR-API-01](/ar/docs/srs/requirements/api#fr-api-01--واجهة-api-العامة)، المرحلة 6) فيستخدمون مفاتيح API للجهة المنظِّمة مع نطاقات، تُرسل كمفتاح bearer، ومع تحديد المعدل لكل مفتاح.
