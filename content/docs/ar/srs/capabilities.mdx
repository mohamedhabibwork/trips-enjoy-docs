تقدّم المنصة مجموعة قدرات واحدة موزَّعة على 28 وحدة. تكثّف هذه الصفحة [وثيقة SRS](/ar/docs/srs) في مصفوفة واحدة: لكل وحدة، القدرات التي تقدمها، والإجراءات التي تكشفها كل قدرة، وقصة المستخدم الكامنة وراءها. اقرأها كاملة لترى شكل المنتج، ثم اتبع التتبع إلى صفحة متطلبات الوحدة.

**دليل القراءة**

- يشير عمود **التتبعات** إلى معرّفات FR-* وUF-* كنص مجرد؛ وتربطها السكربتات بصفحتي [المتطلبات](/ar/docs/srs) و[تدفقات المستخدم](/ar/docs/user-flows).
- عمود **قصة المستخدم** هو صوت المنتج للمتطلبات ذاتها — لا يُستحدث سلوك جديد هنا.
- **الإجراءات** هي الأفعال التي تكشفها القدرة، وليست قائمة API؛ فسطح API محدد في [المتطلبات](/ar/docs/srs/requirements/api).
