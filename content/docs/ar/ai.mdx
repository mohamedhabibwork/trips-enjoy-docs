## خادم MCP

اتصل من أي عميل MCP (Claude Desktop، Cursor، …) بالعنوان `https://<your-host>/api/mcp`. الخادم عديم الحالة — لا مفاتيح ولا جلسات.

مثال على الاستدعاء:

```bash
curl -X POST https://<your-host>/api/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"search","arguments":{"query":"seat hold"}}}'
```

## مفردات معرّفات المتطلبات

| البادئة | المعنى | معرَّفة في |
|---|---|---|
| `FR-` | متطلب وظيفي | صفحات وحدات البرمجيات (SRS) |
| `BR-` | متطلب تجاري | متطلبات الأعمال وقواعدها |
| `BRL-` | قاعدة عمل | متطلبات الأعمال وقواعدها |
| `NFR-` | متطلب غير وظيفي | متطلبات الجودة والواجهة |
| `DAT-` | متطلب بيانات | متطلبات البيانات |
| `OD-` | قرار مفتوح | الامتثال والمخاطر والقرارات |
| `UF-` | تدفق مستخدم | تدفقات المستخدم |
| `D-` | قيد في سجل القرارات — مستند خارجي، ليس جزءًا من هذا الموقع | — |
