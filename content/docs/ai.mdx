This documentation set is designed to be consumed by AI agents as well as people: every page is reachable as clean Markdown, full-text searchable, and queryable through an MCP server.

## MCP server

Connect from any MCP client (Claude Desktop, Cursor, …) to `https://<your-host>/api/mcp`. The server is stateless — no keys, no session.

<TypeTable
  id="mcp-tools"
  type={{
    list_pages: {
      type: '() => string',
      description:
        'The full page index as llms.txt — every page of both editions with titles and URLs.',
    },
    search: {
      type: '(query: string, locale?: "en" | "ar") => SearchResult[]',
      description:
        'Ranked hits with section anchors — the same per-locale index as the site search.',
      parameters: [
        {
          name: 'query',
          description: 'Search query, e.g. "seat hold" or "[FR-SEAT-02](/en/docs/srs/requirements/seat#fr-seat-02--live-seat-map)".',
        },
        {
          name: 'locale',
          description: 'Docs language, "en" (default) or "ar".',
        },
      ],
    },
    get_page: {
      type: '(url: string) => string',
      description:
        'One page as full processed Markdown. URLs are locale-prefixed and i18n-aware: /en/docs/srs/requirements/auth and /ar/docs/... both resolve.',
      parameters: [
        {
          name: 'url',
          description:
            'Page URL, e.g. "/en/docs/srs/requirements/auth" or "/ar/docs/srs/requirements/auth".',
        },
      ],
    },
  }}
/>

Example call:

```bash
curl -X POST https://<your-host>/api/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"search","arguments":{"query":"seat hold"}}}'
```
