# file-service — Entity-Relationship Diagram

## 1. Database

- **Engine**: PostgreSQL 19.
- **Schema**: `file` — owned exclusively by this service.
- **Migrations**: `services/file-service/migrations/`
  (versioned, forward-only, golang-migrate).

The schema is the canonical source of truth for file
metadata. The bytes live behind a **Storage Driver**
(`s3`, `azure_blob`, `oracle_object_storage`, `gcs`,
`local_fs`); the schema stores the resolved
`driver_id` and a driver-opaque `driver_locator`
JSON document that the driver can interpret. The schema
is **driver-agnostic** — adding a new driver does not
require schema changes; only the driver implementation
in `internal/storage/drivers/<id>/` does.

## 2. Cross-Service References

| Column | Type | Refers to | Source of truth |
|--------|------|-----------|------------------|
| `owner_id` | UUID | `Customer` / `Driver` / `Courier` / `Merchant` / etc. | each owner service |
| `tenant_id` | UUID | `Tenant` in `identity-service` | `identity-service` |
| `actor_sub` (audit) | UUID | Keycloak `sub` of admin | `identity-service` (Keycloak) |
| `correlation_id` | UUID | per request | gateway / caller |
| `driver_id` | TEXT | `storage_drivers.id` | this service (driver catalog) |

## 3. Entities

### `File`

A file's metadata.

#### Columns

| Column | Type | Constraints | Notes |
|--------|------|-------------|-------|
| `id` | UUID | PK | UUIDv7 |
| `name` | TEXT | NOT NULL | original filename |
| `mime_type` | TEXT | NOT NULL | e.g. `image/jpeg`, `application/pdf` |
| `size_bytes` | BIGINT | NOT NULL CHECK (size_bytes > 0) | |
| `sha256` | TEXT | NOT NULL | for dedup and integrity |
| `owner_id` | UUID | NOT NULL | cross-ref |
| `owner_type` | TEXT | NOT NULL | `customer`, `driver`, `courier`, `merchant`, `support_ticket`, etc. |
| `tenant_id` | UUID | NULL | for KYC per-tenant |
| `retention_class` | TEXT | NOT NULL | `kyc`, `support_attachment`, `avatar`, `menu_photo`, `safety_recording`, etc. |
| `status` | TEXT | NOT NULL | `pending`, `scanning`, `available`, `quarantined`, `deleted` |
| `driver_id` | TEXT | NOT NULL | FK_ref to `file.storage_drivers.id`; the driver that **currently** holds the canonical bytes |
| `driver_locator` | JSONB | NOT NULL | driver-opaque, e.g. `{"bucket": "...", "key": "...", "version_id": "..."}` for `s3`; `{"container": "...", "blob": "..."}` for `azure_blob`; `{"namespace": "...", "bucket": "...", "object": "..."}` for `oracle_object_storage`; `{"bucket": "...", "object": "..."}` for `gcs`; `{"path": "..."}` for `local_fs`. Stable for the life of the file (changes only on migration). |
| `driver_locale_version` | INT | NOT NULL DEFAULT 1 | bumped on every migration / pinning change; used to invalidate cached signed URLs. |
| `kms_key_id` | TEXT | NULL | per-tenant KMS key (KYC; cloud drivers use driver-native KMS; local FS uses a per-tenant data key). |
| `scan_id` | UUID | NULL | FK to scans (within schema) |
| `scan_result` | TEXT | NULL | `clean`, `infected`, `error` |
| `uploaded_at` | TIMESTAMPTZ | NULL | when the upload completed |
| `scan_completed_at` | TIMESTAMPTZ | NULL | |
| `retention_until` | TIMESTAMPTZ | NOT NULL | computed from retention_class |
| `legal_hold` | BOOLEAN | NOT NULL DEFAULT false | |
| `metadata` | JSONB | NULL | e.g. `{"width": 1920, "height": 1080}` for images |
| `created_at` | TIMESTAMPTZ | NOT NULL DEFAULT now() | |
| `updated_at` | TIMESTAMPTZ | NOT NULL DEFAULT now() | |
| `created_by` | UUID | NOT NULL | |
| `updated_by` | UUID | NOT NULL | |
| `deleted_at` | TIMESTAMPTZ | NULL | soft delete |
| `version` | INT | NOT NULL DEFAULT 1 | optimistic concurrency |

The previous S3-specific columns `s3_bucket`, `s3_key`,
`s3_version_id` are removed. Their content is now
captured in `driver_locator` so the schema is
**driver-agnostic**.

#### Indexes

- PK on `id`
- UNIQUE on `(driver_id, (driver_locator->>'bucket'),
  (driver_locator->>'container'),
  (driver_locator->>'key'), (driver_locator->>'blob'),
  (driver_locator->>'object'), (driver_locator->>'path'))`
  — a functional unique index that resolves, per driver,
  to "no two files share the same logical object name";
  the actual expression is generated by the migration
  and uses the locator key appropriate to the driver's
  kind. Concretely: per-file the migration creates a
  companion `file.driver_object_registry` row (see
  below) so the unique constraint is enforced at the
  schema level regardless of driver.
- BTree on `sha256` (dedup)
- BTree on `(owner_id, owner_type)` WHERE `deleted_at IS NULL`
- BTree on `(retention_class, retention_until)` WHERE
  `status != 'deleted'`
- BTree on `status` WHERE `status = 'pending' OR status = 'scanning'`
- BTree on `correlation_id`
- BTree on `driver_id` (per-driver dashboard queries,
  migrations)

#### Constraints

- CHECK: `status IN ('pending','scanning','available','quarantined','deleted')`
- CHECK: `owner_type IN ('customer','driver','courier','merchant','restaurant','support_ticket','ride_safety','admin')`
- CHECK: `retention_class IN ('kyc','support_attachment','avatar','menu_photo','safety_recording','vehicle_photo','other')`
- CHECK: `size_bytes > 0`
- CHECK: `retention_until > created_at`
- CHECK: `jsonb_typeof(driver_locator) = 'object'` (must be a JSON object — driver convention)
- FOREIGN KEY (logical, application-enforced; not a
  database FK because drivers are recorded in the same
  schema but conceptually come from `file.storage_drivers`):
  every `driver_id` must be present in
  `file.storage_drivers.id` or matched by an external
  driver that the catalog flagged `legacy`.

### `StorageDriver` (driver catalog)

The driver catalog: every Storage Driver this service
can talk to. Sourced from `configuration-service` and
mirrored into this table on `configuration.updated.v1`.

#### Columns

| Column | Type | Constraints | Notes |
|--------|------|-------------|-------|
| `id` | TEXT | PK | driver id (`s3`, `azure_blob`, `oracle_object_storage`, `gcs`, `local_fs`, ...) |
| `kind` | TEXT | NOT NULL | enum (above); same as `id` today, but kept separate in case a renamed driver keeps the same backing kind. |
| `display_name` | TEXT | NOT NULL | human-readable (`AWS S3 — eu-west-1 — kyc`) |
| `state` | TEXT | NOT NULL | `enabled`, `draining`, `disabled` |
| `priority` | INT | NOT NULL DEFAULT 100 | lower wins; admin-set |
| `region` | TEXT | NULL | e.g. `eu-west-1`, `westeurope` |
| `container` | TEXT | NULL | bucket / container name; nullable for legacy drivers reading from external stores |
| `endpoint` | TEXT | NULL | for S3-compatible only |
| `path_style` | BOOLEAN | NOT NULL DEFAULT false | for S3-compatible only |
| `kms_key_id` | TEXT | NULL | per-driver default CMK (KYC) |
| `signed_url_ttl_seconds` | INT | NOT NULL DEFAULT 900 | |
| `max_object_size_bytes` | BIGINT | NOT NULL | per-driver cap |
| `multipart_threshold_bytes` | BIGINT | NOT NULL | when to switch to multipart |
| `is_default` | BOOLEAN | NOT NULL DEFAULT false | env default; at most one row |
| `config_hash` | TEXT | NOT NULL | SHA-256 of the resolved config; used to no-op duplicate config reloads |
| `health` | TEXT | NOT NULL | `healthy`, `degraded`, `unreachable`; flipped by the synthetic probe |
| `health_last_checked_at` | TIMESTAMPTZ | NULL | |
| `metadata` | JSONB | NULL | driver-specific extras (e.g. S3 path-style flags; Azure container soft-delete; OCI namespace; GCS uniform bucket-level access). |
| `created_at` | TIMESTAMPTZ | NOT NULL DEFAULT now() | |
| `updated_at` | TIMESTAMPTZ | NOT NULL DEFAULT now() | |
| `created_by` | UUID | NOT NULL | |
| `updated_by` | UUID | NOT NULL | |
| `version` | INT | NOT NULL DEFAULT 1 | optimistic concurrency |

#### Indexes

- PK on `id`
- BTree on `kind`
- BTree on `state` WHERE `state != 'disabled'`
- BTree on `priority`
- Unique partial index on `(is_default) WHERE is_default`

#### Constraints

- CHECK: `kind IN ('s3','azure_blob','oracle_object_storage','gcs','local_fs')`
- CHECK: `state IN ('enabled','draining','disabled')`
- CHECK: `health IN ('healthy','degraded','unreachable')`
- CHECK: `signed_url_ttl_seconds > 0 AND signed_url_ttl_seconds <= 86400`
- CHECK: `max_object_size_bytes > 0`
- CHECK: `multipart_threshold_bytes >= 0`

### `DriverAssignment` (per-file driver source audit)

Why a file sits on its current driver: explicit pin by
admin, per-tenant override, per-owner-type override,
per-retention-class override, or env default. Recorded
once at upload time and on every pinning change.

#### Columns

| Column | Type | Constraints | Notes |
|--------|------|-------------|-------|
| `id` | UUID | PK | UUIDv7 |
| `file_id` | UUID | NOT NULL | |
| `driver_id` | TEXT | NOT NULL | the chosen driver |
| `source` | TEXT | NOT NULL | `file_pin`, `tenant_override`, `owner_type_override`, `retention_class_override`, `default` |
| `rule_id` | TEXT | NULL | which override rule fired (e.g. `tenant:abc123`, `class:kyc`) |
| `effective_at` | TIMESTAMPTZ | NOT NULL DEFAULT now() | |
| `created_by` | UUID | NOT NULL | who placed it (system or admin sub) |

#### Indexes

- PK on `id`
- BTree on `(file_id, effective_at DESC)`
- BTree on `source`

### `DriverHistory` (migration / pinning audit)

Every change to `files.driver_id` or `files.driver_locator`
is recorded here as an append-only audit row.

#### Columns

| Column | Type | Constraints | Notes |
|--------|------|-------------|-------|
| `id` | UUID | PK | UUIDv7 |
| `file_id` | UUID | NOT NULL | |
| `change_type` | TEXT | NOT NULL | `upload` (initial), `pin` (admin pinned), `migrate` (driver migration), `rollback` (verify failed; restored) |
| `from_driver_id` | TEXT | NULL | NULL on initial upload |
| `to_driver_id` | TEXT | NOT NULL | |
| `from_locator` | JSONB | NULL | NULL on initial upload |
| `to_locator` | JSONB | NOT NULL | |
| `from_sha256` | TEXT | NULL | source object's hash |
| `to_sha256` | TEXT | NULL | destination object's hash (verified on migrate) |
| `verified_sha256` | BOOLEAN | NOT NULL DEFAULT false | `true` only after `migrate` verifies |
| `migration_id` | UUID | NULL | migration batch this row belongs to |
| `actor_sub` | UUID | NOT NULL | admin who triggered, or service identity |
| `reason` | TEXT | NULL | free text; e.g. `EU data residency`, `vendor consolidation` |
| `signature` | TEXT | NOT NULL | HMAC-SHA256 hex |
| `occurred_at` | TIMESTAMPTZ | NOT NULL DEFAULT now() | |
| `metadata` | JSONB | NULL | driver-specific extras (e.g. AWS S3 cross-region replication log; OCI copy-source object) |

#### Indexes

- PK on `id`
- BTree on `(file_id, occurred_at DESC)`
- BTree on `migration_id`
- BTree on `to_driver_id`
- BTree on `(change_type, verified_sha256)`

#### Constraints

- CHECK: `change_type IN ('upload','pin','migrate','rollback')`
- CHECK: `from_driver_id IS NULL OR change_type IN ('migrate','rollback')`

### `DriverObjectRegistry` (logical-key enforcement)

Per-driver "logical object name" registry used to enforce
the equivalent of the old S3 `s3_key UNIQUE` constraint
across all driver kinds.

#### Columns

| Column | Type | Constraints | Notes |
|--------|------|-------------|-------|
| `id` | UUID | PK | UUIDv7 |
| `driver_id` | TEXT | NOT NULL | FK_ref to `storage_drivers.id` |
| `driver_kind` | TEXT | NOT NULL | |
| `bucket` | TEXT | NULL | S3 / GCS / OCI: bucket; Azure: container; local: root |
| `object_key` | TEXT | NULL | S3 / OCI / GCS: full object key; Azure: blob name; local: relative path. NULL when not applicable. |
| `file_id` | UUID | NOT NULL | the canonical `file.id` for this (driver, object) pair |
| `created_at` | TIMESTAMPTZ | NOT NULL DEFAULT now() | |

#### Indexes

- PK on `id`
- UNIQUE on `(driver_id, bucket, object_key)` WHERE
  `object_key IS NOT NULL` — enforces "no two files on
  the same driver share a logical object key".
- BTree on `file_id`

### `DriverHealthEvent` (per-driver synthetic probe log)

Append-mostly log of every synthetic probe result; rolled
up to `storage_drivers.health` gauge on the metrics
layer. Heavy write volume → partitioned monthly.

#### Columns

| Column | Type | Constraints | Notes |
|--------|------|-------------|-------|
| `id` | UUID | NOT NULL | UUIDv7 |
| `occurred_at` | TIMESTAMPTZ | NOT NULL DEFAULT now() | partition key |
| `driver_id` | TEXT | NOT NULL | |
| `result` | TEXT | NOT NULL | `pass`, `warn`, `fail` |
| `latency_ms` | INT | NULL | |
| `error_class` | TEXT | NULL | e.g. `dns`, `timeout`, `auth`, `5xx`, `signature` |
| `correlation_id` | UUID | NOT NULL | |
| `metadata` | JSONB | NULL | |

#### Indexes

- BTree on `(driver_id, occurred_at DESC)`
- BTree on `correlation_id`

#### Partitioning

- Range-partitioned by `occurred_at`, monthly; 90-day
  retention.

### `Outbox` and `Inbox`

Standard outbox and inbox tables per `EVENT_ARCHITECTURE.md`.
See `geolocation-service/ERD.md` for the canonical DDL.

## 5. DDL Sketch

```sql
CREATE SCHEMA IF NOT EXISTS file;
SET search_path = file, public;

-- Driver catalog ----------------------------------------------------------------
CREATE TABLE file.storage_drivers (
    id TEXT PRIMARY KEY,
    kind TEXT NOT NULL CHECK (kind IN ('s3','azure_blob','oracle_object_storage','gcs','local_fs')),
    display_name TEXT NOT NULL,
    state TEXT NOT NULL CHECK (state IN ('enabled','draining','disabled')),
    priority INT NOT NULL DEFAULT 100,
    region TEXT,
    container TEXT,
    endpoint TEXT,
    path_style BOOLEAN NOT NULL DEFAULT false,
    kms_key_id TEXT,
    signed_url_ttl_seconds INT NOT NULL DEFAULT 900
        CHECK (signed_url_ttl_seconds > 0 AND signed_url_ttl_seconds <= 86400),
    max_object_size_bytes BIGINT NOT NULL CHECK (max_object_size_bytes > 0),
    multipart_threshold_bytes BIGINT NOT NULL CHECK (multipart_threshold_bytes >= 0),
    is_default BOOLEAN NOT NULL DEFAULT false,
    config_hash TEXT NOT NULL,
    health TEXT NOT NULL CHECK (health IN ('healthy','degraded','unreachable')),
    health_last_checked_at TIMESTAMPTZ,
    metadata JSONB,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    created_by UUID NOT NULL,
    updated_by UUID NOT NULL,
    version INT NOT NULL DEFAULT 1
);
CREATE INDEX storage_drivers_kind_idx ON file.storage_drivers (kind);
CREATE INDEX storage_drivers_state_idx ON file.storage_drivers (state)
    WHERE state <> 'disabled';
CREATE INDEX storage_drivers_priority_idx ON file.storage_drivers (priority);
CREATE UNIQUE INDEX storage_drivers_is_default_uk ON file.storage_drivers (is_default)
    WHERE is_default;

-- Files (driver-agnostic) -------------------------------------------------------
CREATE TABLE file.files (
    id UUID PRIMARY KEY,
    name TEXT NOT NULL,
    mime_type TEXT NOT NULL,
    size_bytes BIGINT NOT NULL CHECK (size_bytes > 0),
    sha256 TEXT NOT NULL,
    owner_id UUID NOT NULL,
    owner_type TEXT NOT NULL CHECK (owner_type IN ('customer','driver','courier','merchant','restaurant','support_ticket','ride_safety','admin')),
    tenant_id UUID,
    retention_class TEXT NOT NULL CHECK (retention_class IN ('kyc','support_attachment','avatar','menu_photo','safety_recording','vehicle_photo','other')),
    status TEXT NOT NULL CHECK (status IN ('pending','scanning','available','quarantined','deleted')),
    driver_id TEXT NOT NULL, -- FK_ref to file.storage_drivers.id; application-enforced
    driver_locator JSONB NOT NULL CHECK (jsonb_typeof(driver_locator) = 'object'),
    driver_locale_version INT NOT NULL DEFAULT 1,
    kms_key_id TEXT,
    scan_id UUID,
    scan_result TEXT CHECK (scan_result IS NULL OR scan_result IN ('clean','infected','error')),
    uploaded_at TIMESTAMPTZ,
    scan_completed_at TIMESTAMPTZ,
    retention_until TIMESTAMPTZ NOT NULL CHECK (retention_until > created_at),
    legal_hold BOOLEAN NOT NULL DEFAULT false,
    metadata JSONB,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    created_by UUID NOT NULL,
    updated_by UUID NOT NULL,
    deleted_at TIMESTAMPTZ,
    version INT NOT NULL DEFAULT 1
);
CREATE INDEX files_sha256_idx ON file.files (sha256);
CREATE INDEX files_owner_idx ON file.files (owner_id, owner_type) WHERE deleted_at IS NULL;
CREATE INDEX files_retention_idx ON file.files (retention_class, retention_until) WHERE status != 'deleted';
CREATE INDEX files_status_pending_idx ON file.files (status) WHERE status IN ('pending','scanning');
CREATE INDEX files_correlation_idx ON file.files (correlation_id);
CREATE INDEX files_driver_idx ON file.files (driver_id);

CREATE TABLE file.scans (
    id UUID PRIMARY KEY,
    file_id UUID NOT NULL REFERENCES file.files(id) ON DELETE CASCADE,
    provider TEXT NOT NULL,
    status TEXT NOT NULL CHECK (status IN ('pending','running','clean','infected','error')),
    result TEXT CHECK (result IS NULL OR result IN ('clean','infected','error')),
    threat_name TEXT,
    raw_response JSONB,
    started_at TIMESTAMPTZ NOT NULL,
    completed_at TIMESTAMPTZ,
    attempt INT NOT NULL DEFAULT 1,
    error TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    created_by UUID NOT NULL
);
CREATE INDEX scans_file_idx ON file.scans (file_id, started_at DESC);
CREATE INDEX scans_status_idx ON file.scans (status) WHERE status IN ('pending','running');

CREATE TABLE file.access_log (
    id UUID NOT NULL,
    occurred_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    file_id UUID NOT NULL,
    driver_id TEXT NOT NULL, -- driver id tag for per-driver dashboards
    actor_sub UUID,
    action TEXT NOT NULL,
    ip INET,
    user_agent TEXT,
    metadata JSONB,
    correlation_id UUID NOT NULL,
    PRIMARY KEY (id, occurred_at)
) PARTITION BY RANGE (occurred_at);

-- Idempotent pre-creation; safe to rerun as part of the maintenance job.
CREATE TABLE IF NOT EXISTS file.access_log_2026_07
    PARTITION OF file.access_log
    FOR VALUES FROM ('2026-07-01 00:00:00+00') TO ('2026-08-01 00:00:00+00');

CREATE INDEX access_log_file_idx ON file.access_log (file_id, occurred_at DESC);
```

## 6. Audit Columns

Every mutable table has `created_at`, `updated_at`, `created_by`,
`updated_by`. `access_log`, `driver_history`, and
`driver_health_events` are append-mostly.

## 7. Soft Delete

`files` uses `deleted_at`. Reads filter
`WHERE deleted_at IS NULL`. Retention policies and overrides
are also soft-deletable. **Driver tables are not
soft-deletable** — drivers are administrative entities;
they are added / drained / disabled, never deleted.

## 8. JSONB Usage

| Table | Column | Justification |
|-------|--------|---------------|
| `files` | `metadata` | image dimensions, etc. |
| `files` | `driver_locator` | driver-opaque; each driver decides its own shape |
| `scans` | `raw_response` | provider-specific; never queried |
| `access_log` | `metadata` | e.g. `via`, `correlation_id` of the action |
| `storage_drivers` | `metadata` | driver-specific configuration (S3 path-style, Azure soft-delete, OCI namespace, GCS uniform-BLA, local root path) |
| `driver_history` | `from_locator`, `to_locator`, `metadata` | driver-opaque; for forensic audit |
| `driver_health_events` | `metadata` | synthetic probe extras |

## 9. Partitioning

| Table | Partition strategy | Retention |
|-------|--------------------|-----------|
| `access_log` | RANGE by `occurred_at`, monthly | 1y |
| `driver_health_events` | RANGE by `occurred_at`, monthly | 90 days |

## 10. Data Retention

| Table | Retention | Purged by |
|-------|-----------|-----------|
| `files` (metadata) | per `retention_class` | retention job |
| `files` (driver bytes) | per `retention_class` | retention job (calls the resolved driver's `DeleteObject`) |
| `driver_object_registry` | cascading on file hard delete | cascade |
| `driver_assignments` | indefinite (immutable) | never |
| `driver_history` | indefinite (immutable audit) | never |
| `scans` | cascading on file hard delete | cascade |
| `access_log` | 1y | partition drop |
| `driver_health_events` | 90 days | partition drop |
| `retention_policies` | indefinite | soft delete only |
| `retention_overrides` | cascading on file hard delete | cascade |
| `outbox` | 24h after publish | partition drop |
| `inbox` | 7d | hard delete |

## 11. Migration Considerations

- **Adding a new retention class** is a config change
  (insert a new `retention_policies` row).
- **Adding a new Storage Driver** is purely application-
  level (drop a new package under
  `internal/storage/drivers/<id>/` and add a new
  `storage_drivers` row on `configuration.updated.v1`).
  The schema is unchanged. No migration is required for
  shipping a new driver implementation.
- **Switching a tenant's driver** is an admin action that
  records a `driver_history` row and (optionally)
  enqueues a bulk migration; switching the env default
  is a config change only and affects future uploads.
- **Bucket / container changes** for an existing driver
  require a multi-step plan: dual-write, backfill, switch
  reads, drop old. Each step is recorded as a
  `driver_history` row.
- **Driver decommission**: drain the driver
  (`state = 'draining'`), run the migration worker until
  all canonical bytes have left, then `state = 'disabled'`.
  Old `driver_history` rows are kept indefinitely.
- **KMS key rotation** for KYC files is a background job
  that re-encrypts each file on the active driver with
  the new key (driver-native primitive: S3 `CopyObject`
  with new `KMSKeyId`, Azure `Copy Blob` with new
  encryption scope, OCI `CopyObject` with new KMS key
  id, GCS `rewrite` with new CMEK).
- **Right-to-erasure** is a background job: for each
  user, list files, soft-delete, then call the active
  driver's `DeleteObject` within 1h.
